# Teaboom — карточка товара

Тестовое задание: верхняя часть карточки **Ананасовый улун** для [teaboom.ru](https://teaboom.ru/product/ananasovij-ulun).

Вёрстка на HTML5, SCSS и vanilla JS. Методология — BEM. Без Bootstrap и шаблонов магазинов.

## Что сделано

- изображение, название, категория, фасовка, артикул, цены, кнопка «В корзину», короткое описание;
- переключение фасовки меняет цену, старую цену, артикул и выбранное состояние;
- кнопка «В корзину»: обычное состояние и hover (как на Teaboom: жёлтый → тёмный);
- адаптив: 1440 / 768 / 375;
- фото и логотип с действующего сайта Teaboom.ru.

Реальная корзина не подключалась — по клику показывается короткое уведомление.

## Запуск

Нужны Node.js 18+ и npm. Команды одинаковые в **macOS** (Terminal) и **Windows** (PowerShell или cmd).

```bash
npm install
npm run dev
```

Страница откроется на [http://127.0.0.1:4321](http://127.0.0.1:4321).

Сборка статики:

```bash
npm run build
npm run preview
```

Готовые файлы окажутся в `dist/`. Сборка на Sass, `copyfiles` и `serve` — без Vite и без своих Node-скриптов, поэтому ставится и запускается на Windows и Mac.

На GitHub Pages (адрес вида `username.github.io/test-teaboom/`) пути в HTML относительные, иначе браузер ищет стили и картинки в корне `username.github.io`, а не в репозитории. В репозиторий нужно коммитить собранный `styles/main.css` (`npm run css`).

## Структура

```text
index.html                 — разметка карточки
src/scripts/               — JS карточки
src/styles/                — SCSS по блокам BEM
images/                    — фото товара и логотип
```
